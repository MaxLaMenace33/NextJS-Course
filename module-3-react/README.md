# Module 3 : Maîtriser React (JSX/TSX)

Ce module vous permettra de maîtriser React, la bibliothèque JavaScript pour créer des interfaces utilisateur.

## Pourquoi React ?

- **Composants réutilisables** : Architecture modulaire
- **Virtual DOM** : Performance optimisée
- **Écosystème riche** : Nombreuses bibliothèques
- **Utilisé par Next.js** : Base pour le Module 4

## Prérequis

- Modules 1 et 2 terminés
- Node.js et npm installés
- Créer une app React :

```bash
# Avec Vite (recommandé)
npm create vite@latest my-react-app -- --template react-ts
cd my-react-app
npm install
npm run dev
```
