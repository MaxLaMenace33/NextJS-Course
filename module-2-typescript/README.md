# Module 2 : Maîtriser TypeScript

Ce module vous permettra de maîtriser TypeScript, le superset de JavaScript qui ajoute le typage statique.

## Pourquoi TypeScript ?

- **Typage statique** : Détecte les erreurs avant l'exécution
- **Meilleure autocomplétion** : IntelliSense amélioré
- **Code plus maintenable** : Documentation auto-générée
- **Refactoring facilité** : Les erreurs sont détectées automatiquement

- Avoir complété le Module 1 (JavaScript)
- Node.js installé
- Un éditeur avec support TypeScript (VS Code recommandé)

## Installation

Pour tester vos exercices TypeScript :

```bash
# Installer TypeScript globalement
npm install -g typescript

# Compiler un fichier .ts
tsc fichier.ts

# Ou utiliser ts-node pour exécuter directement
npm install -g ts-node
ts-node fichier.ts
```
