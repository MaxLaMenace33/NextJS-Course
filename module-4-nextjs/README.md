# Module 4 : Maîtriser Next.js

Ce module vous permettra de maîtriser Next.js, le framework React pour la production.

## Pourquoi Next.js ?

- **Server-Side Rendering (SSR)** : Performance et SEO
- **Static Site Generation (SSG)** : Sites ultra-rapides
- **App Router** : Routing moderne et intuitif
- **API Routes** : Backend intégré
- **Optimisations automatiques** : Images, fonts, etc.

## Installation

```bash
# Créer un nouveau projet Next.js
npx create-next-app@latest my-nextjs-app

# Options recommandées :
# ✅ TypeScript
# ✅ ESLint
# ✅ Tailwind CSS
# ✅ App Router
# ✅ Import alias (@/*)

cd my-nextjs-app
npm run dev
```
